# Screenshots Guide (`docs/screenshots/`)

Place captured screenshots from the running app (`npm run dev` on `http://localhost:3000` or the live demo at `https://northeastconnect-gamma.vercel.app/`) into this folder using the filenames below:

1. `01-situation-board.png` — Situation Board (`/board`) showing Advisories, Lifeline Corridors, and Community Reports.
2. `02-report-form.png` — Report / Request Help (`/report`) showing Quick SOS and 3-Step workflow.
3. `03-outbox-offline.png` — My Outbox drawer while **Simulate Offline** is active, displaying *"Saved on your device. Not yet sent."*
4. `04-map-route.png` — Interactive Map on `/board` with `"Locate me"` blue marker and OSRM / fallback route preview.
5. `05-coordinator-desk.png` — Coordinator Desk (`/coordinator`) showing Verification Status vs. Assistance Workflow and Audit History.
